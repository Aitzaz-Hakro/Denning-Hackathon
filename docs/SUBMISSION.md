# Submission Requirements

The organizer's rules, turned into a checklist. A missing item means the project cannot be judged.

## Event

- Day 1: Friday 23 October 2026, 5 hours, Auditorium, DITE, Hyderabad.
- Day 2: Saturday 24 October 2026, results and social.
- Team size: up to 3.

## Must-pass requirements

- [ ] Working web app.
- [ ] Uses AI (API, pre-trained model, or own model).
- [ ] Deployed online with a link that opens for anyone.
- [ ] Public GitHub repository with a complete README.
- [ ] Demo video, 3 to 5 minutes, uploaded to Google Drive.
- [ ] Code written during the 5 hours.
- [ ] No API keys or passwords in code; environment variables only.

## Pre-event checklist

Prepare before Friday so the 5 hours go into building.

Accounts:

- [ ] GitHub account for every member; everyone can clone, commit, and push.
- [ ] Vercel account.
- [ ] Google account with Drive space for the video.
- [ ] AI API key with the free quota checked.

Software on every laptop:

- [ ] Git, VS Code, Node.js.
- [ ] Project dependencies installed (`npm install`).
- [ ] Screen recorder (OBS Studio or the phone recorder).

Practice once:

- [ ] Build a tiny app that calls one AI model or API.
- [ ] Deploy it.
- [ ] Push it to GitHub.
- [ ] Record a one-minute video.

Agree on roles:

| Role | Owns |
| --- | --- |
| AI lead | Model/API choice and the AI call |
| App lead | Interface and main user flow |
| Ship lead | GitHub, deployment, README, demo video |

## Before submitting

1. [ ] Push the final code to the public GitHub repository.
2. [ ] Complete the README with the project title, description, live link, and demo video link.
3. [ ] Deploy the web app and copy the live URL.
4. [ ] Upload the demo video to Google Drive.
5. [ ] Set every Drive link to "Anyone with the link can view".
6. [ ] Open every link in an incognito window and confirm it works.
7. [ ] Fill the Google Form and submit before the 5 hours end.
8. [ ] Keep the submission confirmation.

## Submission fields

| Field | What to enter |
| --- | --- |
| Team name and members | As registered |
| Team lead contact | Name, email, phone |
| Project title and description | Short title and two or three sentences |
| GitHub repository | Public repo URL |
| Live link | Deployed web URL |
| Demo video | Google Drive link |

## Demo video (3 to 5 minutes)

- [ ] Show the problem in the first 20 seconds.
- [ ] Show the live app, not slides.
- [ ] Show the AI feature working.
- [ ] Show the main user flow end to end.
- [ ] Mention the stack briefly.
- [ ] Upload to Drive and test the link in incognito.

## Deadline rules

- No code may be pushed to GitHub after the deadline.
- Late submissions are not accepted.
- A missing link means the project cannot be judged.
